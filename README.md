TecHub is a modern, automated web platform that curates and delivers the latest news in Technology, Artificial Intelligence, and the Vue.js ecosystem. 

Built with a focus on performance, clean UI, and scalable architecture, this project serves as a bridge between automated backend data gathering and a highly optimized front-end experience.

## 🚀 Live Preview
Check out the live application: **[techub-bay.vercel.app](https://techub-bay.vercel.app)**

## 💡 Architecture & Tech Stack

This project demonstrates a decoupled architecture, separating the data-gathering automation from the front-end presentation layer.

### Front-End (VILT Stack aligned)
- **Vue.js / Nuxt 3:** Chosen for its reactivity, component-based architecture, and Server-Side Rendering (SSR) capabilities, ensuring fast load times and great SEO.
- **TypeScript:** Implemented to maintain type safety, reduce runtime errors, and ensure clean, maintainable, and self-documenting code.
- **Tailwind CSS:** Used for crafting a responsive, accessible, and elegant user interface without leaving the HTML context.

### Back-End & Automation
- **Python:** Powers the backend automation scripts responsible for scraping, curating, and processing news articles from various sources before delivering them to the front-end.

## ✨ Key Features
- **Automated Content Curation:** Python scripts run autonomously to fetch the latest tech news.
- **Modern UI/UX:** Clean, responsive design built entirely with Tailwind CSS, focusing on readability and user experience.
- **Type-Safe Components:** Reusable Vue components strictly typed with TypeScript.
- **Optimized Performance:** Leveraging Nuxt 3's hybrid rendering for lightning-fast navigation.
